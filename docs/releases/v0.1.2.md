# v0.1.2 · 屏幕自适应

> 发布日期：2026-11-27
> 安装包：`XB-SVCB-Mobile-0.1.2.apk` · 818 KB · `versionCode 1` · Android 10+（minSdk 29）
> SHA-256：`1449986B32F8801EF77D08F9B3E83645FB897000558867A12506317E1D7AB69B`

## 概要

本次更新把「填写服务地址与 API Key」的连接页并入了全站统一的尺寸体系：它不再比
其它页面大一圈。所有页面以 390×844 为 1× 基准随屏幕宽度缩放，窄屏自动收紧、
矮屏压缩纵向节奏，连接页在 360×640 及以上可以完整一屏放下。

## 主要变化

### 界面与布局

| 项目 | 改前 | 改后 |
| --- | --- | --- |
| 连接页标题 | 27px 固定 | 与其它页面共用令牌（390 宽 25px、320 宽 20.5px） |
| 页面左右边距 | 20px 固定 | 16px（随屏宽 13–18px） |
| 卡片内边距 | 16px | 14px（随屏宽 12–15px） |
| 连接页容器 | `min-height: 100dvh` 撑满 | `flex: 1` + 自身滚动，与 `.app-main` 一致 |
| 页头 / 标签栏 / 按钮 / 输入框 | 固定 px | 共用尺寸令牌，同步缩放 |

- 新增自适应尺寸令牌：`clamp()` 随屏宽缩放，并带 px 兜底（旧版 WebView 不丢样式）。
  320px 收紧，390–440px 之间到达各自上限后不再放大。
- 矮屏（高度 ≤700px）自动压缩标题、控件与间距，并收起连接页的装饰副标题；
  ≤560px 再压一档。
- 关闭安卓 WebView 的字体放大（`text-size-adjust: 100%`），各机型字号一致。

### 修复

- 连接页在窄屏上溢出：360×640 改前超出 218px、320×568 超出 339px，
  改后分别为 0 与 84px（仅需轻微滚动）。
- 连接页用 `100dvh` 撑满导致的底部空白与滚动位置错位。

## 安装

```powershell
adb install -r dist/XB-SVCB-Mobile-0.1.2.apk
```

或把 APK 传到手机侧载安装。`versionCode` 与上一版同为 1、签名不变，可直接覆盖安装。

首次使用：电脑端「资料库 → API 接入」启动服务并切到局域网模式，手机填
`http://电脑局域网IP:8760` 与 `XB-SVCB-…` Key 后连接。

## 已知限制

- 320×568 与横屏（高度 360px）下连接页仍需少量滚动。
- 局域网 HTTP 为明文传输，地址与 Key 只保存在应用私有存储，请勿把端口映射到公网。
- 未在真实手机上验证文件选择器、DownloadManager 与 `file://` 音频播放，
  首次安装请确认这三项。
